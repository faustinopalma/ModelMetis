ModelMetis

ModelMetis receives a machine recording, turns it into signal-processing diagrams and measurements, and asks a general multimodal model to study them beside recordings of known conditions. The model names the matching condition or hands the case to a person.

On reserved Jin motor recordings the method recognized 11 of 12 windows and correctly set aside 2 of 4 cases whose condition had no reference. On Ottawa motors, whose references come from another speed and load profile, it recognized 4 of 16; references for every operating regime are the current focus.

From audio to a decision in four steps

  1. Analyze

    The system receives the audio and computes a deterministic DSP report for each ten-second recording: waveform, FFT, Welch spectrum, spectrogram, band power, envelope and autocorrelation diagrams with their measurements.

  2. Supply references

    Each known condition contributes one report, from a recording chosen before testing. The unknown report carries no label.

  3. Compare

    A general multimodal model studies the unknown report beside every reference and cites evidence from both. One configuration adds Welch spectral distances.

  4. Decide

    The model returns the best-supported known condition, or different so that a person reviews the case.

Every recording is published with its diagrams, so you can listen to an unknown sample and each reference side by side.

Good references make good decisions

A reference should resemble its condition as it will be recorded: microphone position, speed and load. References are fixed before testing, by rules that use no test outcome.

When recordings with the same label behave very differently, the label covers several acoustic families or operating regimes, and each gets its own reference. Such differences can come from speed, load or mounting as well as from the fault itself.

On Jin, front-microphone references carried over to right-microphone recordings of the same four conditions. On Ottawa, references from operating profile 1 now need companions from the other profiles.

What we are improving

  • References for every operating regime. By Welch distance, 14 of 16 Ottawa profile-2 recordings lie closer to another class's profile-1 reference; references from each profile and load address this directly.
  • Separating close classes. The Jin magnet-fracture and tight-bearing references lie 3.04 dB apart, which explains the one missed magnet-fracture window and one wrong acceptance.
  • Explanations that follow the numbers. In one excluded-class test the model accepted a reference 6.35 dB away on the strength of similar levels and a shared 16 kHz ridge.
  • Balancing recognition and review. Calibrated thresholds set aside all four excluded-class windows together with the three magnet-fracture windows.

The current evidence comes from two public motor datasets, few acquisitions and recordings the project has already studied. Fresh recordings and blind listening comparisons are the next validation steps. Published scores from other models use their own sensors, splits and label budgets and serve as context.

Other directions explored

We also tested a wider set of 26 diagrams, the removal of selected diagram types and an adaptive class memory built from aggregated references. On 72 Ottawa acquisitions, fixed memory gave 16 correct, 11 wrong and 45 reviewed decisions; adaptive memory gave 18 correct, 41 wrong and 13 reviewed. The archive keeps every measurement and guides the current focus on references.
