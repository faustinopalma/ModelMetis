ModelMetis

A multimodal model compares the signal-processing report of an unknown machine recording with reports of recordings whose condition is known. It names the matching condition or answers different.

Research evidence, not an approved diagnostic. The method recognized 11 of 12 reserved Jin windows but rejected only 2 of 4 excluded-class tests. It failed on Ottawa, where one reference per class did not represent a changed operating profile: 4 of 16 correct.

The model reads evidence, not audio

  1. Measure

    Each ten-second recording becomes a deterministic DSP report: waveform, FFT, Welch spectrum, spectrogram, band power, envelope and autocorrelation diagrams, plus their numerical measurements.

  2. Supply references

    One report per known condition, from a recording whose label was chosen before testing. The unknown report has no label.

  3. Compare

    The model compares the unknown report with every reference and must cite evidence from both sides. One configuration also supplies Welch spectral distances.

  4. Decide or abstain

    It returns the best-supported known condition, or different when no reference is similar. Different sends the case to a person; it is not a new diagnosis.

Audio is published so people can listen to each recording beside its reference. The model received only diagrams and measurements.

Representative references are a condition of the method

A reference must look like the condition as it will be met: the same kind of microphone position, speed and load. Select references before testing and never from test outcomes.

When two recordings with the same label behave very differently, the label covers more than one acoustic family or operating regime. Keep both as separate references instead of averaging them. Such a difference does not by itself prove two distinct physical faults.

On Jin, front-microphone references transferred to right-microphone recordings of the same four conditions. On Ottawa, profile-1 references did not represent profile-2 acquisitions of the same motors.

Where the method fails

  • References miss the regime. By Welch distance, 14 of 16 Ottawa profile-2 recordings lay closer to another class's profile-1 reference than to their own.
  • References lie close together. Jin magnet fracture and tight bearing differ by 3.04 dB; magnet-fracture windows were missed, and an excluded magnet-fracture window was accepted as tight bearing.
  • The model can argue past the numbers. In the healthy excluded-class test it accepted a reference 6.35 dB away.
  • A stricter rule moves the error. Calibrated thresholds rejected all four excluded windows but also all three magnet-fracture windows.

Two public datasets, few acquisitions and previously used recordings limit every number above. No general reliability, state-of-the-art or human-parity claim is made. Published scores from other models use different sensors, splits or label budgets and are context, not a comparison.

Later variants did not improve safety

Removing diagram types and adding adaptive class memory were tested afterwards. On 72 Ottawa acquisitions, fixed memory gave 16 correct, 11 wrong and 45 review; adaptive memory gave 18 correct, 41 wrong and 13 review. These measured limits are kept in the archive.
