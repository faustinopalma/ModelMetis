## Frozen Protocol

Source: Mert Sehri and Patrick Dumond, University of Ottawa, UOEMD-VAFCVS v2 (2026), [DOI 10.17632/msxs4vj48g.2](https://doi.org/10.17632/msxs4vj48g.2), CC BY 4.0. Changes: microphone extraction, per-record peak normalization to 0.95, conversion to mono PCM16 WAV, opaque naming and grouped splitting. The 1,386,524,669-byte ZIP has SHA-256 `9c5e67145400e3806c4deb9df28cf41f2ccae22b9a7c5f1e8ee1b1a4d38c0907`. All 128 CSV/MAT microphone pairs matched within absolute tolerance 1e-6, with no relative tolerance; all MAT arrays had 420,000 rows and five finite columns. Only column 2 was used. There are eight classes and 16 acquisitions per class, not 256 independent recordings. Import/audit took 101 seconds after a 43.4-second download.

Speed profile 1, both loads, supplied 16 development acquisitions; profiles 2-7 supplied 96 training acquisitions; profile 8 supplied 16 final acquisitions. Splitting preceded any processing into model features. Profile 1 is constant 15 Hz; profile 8 decreases from 60 to 30 Hz, introducing operating-condition shift. Physical motors are shared across partitions and unit identity may determine fault class. This is not an unseen-motor test, nor evidence about heavy-vehicle engines. No duplicate canonical audio hashes were found. Original labels and source mappings are stored separately from operational manifests; neither teacher nor trainer receives them as inputs.

The two predefined candidates in [audio-prompts.json](../configs/audio-prompts.json) were compared only on development macro-F1, with input order breaking ties. `literal` scored accuracy 0.125 and macro-F1 0.027778; `acoustic` scored accuracy 0.125 and macro-F1 0.038462. The acoustic descriptions are hypotheses about sounds, not sample-specific publisher annotations. `acoustic` was frozen at `2026-09-18T09:32:52Z`, before silver collection and final evaluation, with prompt SHA-256 `25cbe12f81776e52478ca635df90b1ab88b8b6c867b9a428d318e01017022446`. Candidate revision, zero acceptance threshold and specialist parameters were unchanged afterward. Final evaluation was written at `2026-09-18T09:38:00Z`.

The teacher was `laion/clap-htsat-unfused`, requested revision `8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a`, in evaluation/inference mode on CPU with four PyTorch threads. Audio was resampled from 42 kHz to 48 kHz using SciPy polyphase resampling. Each request contained only canonical audio, the eight-class taxonomy and fixed text descriptions. The adapter used the largest softmax similarity as its label; these scores are uncalibrated, and threshold zero deliberately accepted every valid top-one result for this baseline. This must not be confused with a reliable abstention policy.

All 96 training acquisitions received silver labels: 48 healthy, 39 broken rotor bars, and nine bowed rotor. The other five categories never appeared as training targets. Teacher inference took 156.782594 seconds plus 14.789293 seconds loading; the combined collection/training command took 198.3 seconds. The specialist used 48 log-spaced Welch spectral bands (20-20,000 Hz), log10 power, `StandardScaler`, and `LogisticRegression(max_iter=1000, random_state=17)`. Training and artifact writing took 13.074640 seconds. No publisher targets, class balancing from reference truth, or fallback ground-truth labels were used. The classifier could not learn target classes absent from its silver labels.

The specialist artifact is 3,857 bytes, SHA-256 `a833644c44ddf69f88843fcd677f6f456b48b66f616620608b58658f1e881f94`. Load only locally produced, trusted joblib artifacts: deserialization can execute code. The existing final set has now been examined. Further development needs a separately reserved confirmatory set before claiming another blind result; do not tune against these final errors.

## Evidence And Boundaries

Versioned aggregate evidence: [source audit](ottawa-v1-audit.json), [development comparison](ottawa-v1-development.json), [silver training](ottawa-v1-training.json), and [final metrics with confusion matrices](ottawa-v1-final.json). These are exact exports of the generated local reports. Before export, prompt selection, silver bytes, training manifest, final prediction hashes and evaluated model hash were checked for consistent lineage. Reports contain no per-example IDs or source mappings.

Individual predictions and weights remain under ignored `artifacts/ottawa-v1/`; the archive, sanitized partitions, sealed references, runtime and model cache remain under ignored `data/`. The importer and evaluator can read references. The teacher and specialist functions cannot accept a reference manifest through their declared operational interfaces. Tests deliberately invert reference truth and intercept the actual classifier `fit`, as well as reject reference fields, development/test input, altered prompt/audio hashes, duplicate or missing predictions, and unknown statuses before fitting. Empty or incomplete evaluations fail; abstentions count as errors rather than disappearing from metrics.

This is application-level separation, not OS-enforced isolation: an unrestricted process running as the same local user can still read the sealed directory. Hashes detect mismatches but do not authenticate a forged teacher record. Cloud identities, separately scoped stores, immutable access logs and enforced partition permissions remain required. Public-benchmark exposure during foundation-model pretraining is unknown. No automatic collection schedule, experiment budget enforcer, retry controller, promotion, fallback router or rollback has been implemented.

The application/test environment remains `.venv` on Python 3.13.13 ARM64. The experiment used `data/ml-runtime/Scripts/python.exe`, Python 3.13.13 `win-amd64`, with PyTorch 2.8.0+cpu, Transformers 4.57.6, NumPy 2.5.3, SciPy 1.18.1, scikit-learn 1.9.1, librosa 0.11.0 and joblib 1.6.0. CUDA was unavailable. The [48-package snapshot](requirements-windows-x64.txt) passed `uv pip check`; it is the measured Windows x64 environment, not a cross-platform, hashed lockfile. Base application/dev dependencies are separate. Installing from project extras requires both `ml` and `teacher` for inference, or just `ml` for training/evaluation, in addition to the project itself.

The ARM64 application environment had no compatible PyTorch wheel on the inspected feeds. The package tool initially reported success despite the missing import. An existing x64 Python interpreter and a separate venv resolved it without changing the application interpreter. Packages came from the configured `https://packagefeedproxy.microsoft.io/pypi/simple/` feed after direct PyPI TLS failed; certificate validation was not disabled. Provision a Linux/AML environment and verify it independently rather than assuming this Windows snapshot is portable.

Transformers also downloaded a generated safetensors conversion at revision `79b58ed25fc00386262a2bea4b19fd21dc4310a0`, despite the requested original revision. The original 614,525,833-byte checkpoint has SHA-256 `1cd3c601bc4afe0fa87be3de4c13dd2cfadd249fac1e29acf74a9b296c3219bb`; the 614,431,440-byte conversion has SHA-256 `abba8294f0c63d00eb3f8d998dacd16177cc5860cad3a11618e7f361a75587fe`. All 447 named tensors, including dtypes, compared exactly equal. Per-invocation weight-format selection was not recorded, but this comparison establishes equivalence of the two cached files. Preserve these hashes; a requested model revision alone did not describe all fetched artifacts.

## Reproduction

Run from the repository root with a verified ML interpreter. The existing dataset and experiment directories are immutable inputs to this reproduction. Importing to a new directory creates fresh opaque UUIDs: preserve the original manifests to reproduce their exact identity and ordering. Outputs refuse overwrite. Commands below use a new output prefix and reproduce an already disclosed benchmark; they do not constitute a new blind final test. Full runs require internet access for uncached model files and must not run implicitly in unit tests or pull-request CI.

```powershell
$timer=[Diagnostics.Stopwatch]::StartNew(); try { $env:PYTHONPATH='src'; $env:HF_HOME=(Join-Path $PWD 'data/hf-cache'); $env:HF_HUB_DISABLE_IMPLICIT_TOKEN='1'; $env:PYTHONUTF8='1'; $python='data/ml-runtime/Scripts/python.exe'; $dataset='data/ottawa-simulation-v1'; $run='artifacts/ottawa-reproduction'; $revision='8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a' } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python -m modelmetis.simulation infer --input "$dataset/development" --prompts configs/audio-prompts.json --variant literal --revision $revision --output "$run/dev-literal"; if ($LASTEXITCODE) { throw 'Teacher failed' } } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python -m modelmetis.simulation infer --input "$dataset/development" --prompts configs/audio-prompts.json --variant acoustic --revision $revision --output "$run/dev-acoustic"; if ($LASTEXITCODE) { throw 'Teacher failed' } } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python scripts/evaluate_audio.py --references "$dataset/sealed/references.json" --predictions "$run/dev-literal/predictions.json" "$run/dev-acoustic/predictions.json" --partition development --output "$run/development-report.json"; if ($LASTEXITCODE) { throw 'Evaluation failed' }; $selection=Get-Content "$run/development-report.json" -Raw | ConvertFrom-Json } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python -m modelmetis.simulation infer --input "$dataset/train" --prompts configs/audio-prompts.json --variant $selection.selected_variant --revision $revision --output "$run/collection"; if ($LASTEXITCODE) { throw 'Collection failed' } } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python -m modelmetis.simulation train --input "$dataset/train" --silver "$run/collection/predictions.json" --output "$run/specialist"; if ($LASTEXITCODE) { throw 'Training failed' } } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python -m modelmetis.simulation infer --input "$dataset/test" --prompts configs/audio-prompts.json --variant $selection.selected_variant --revision $revision --output "$run/test-teacher"; if ($LASTEXITCODE) { throw 'Teacher failed' } } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python -m modelmetis.simulation predict --input "$dataset/test" --model "$run/specialist/specialist.joblib" --output "$run/test-specialist"; if ($LASTEXITCODE) { throw 'Prediction failed' } } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
$timer=[Diagnostics.Stopwatch]::StartNew(); try { & $python scripts/evaluate_audio.py --references "$dataset/sealed/references.json" --predictions "$run/test-teacher/predictions.json" "$run/test-specialist/predictions.json" --partition test --output "$run/final-report.json"; if ($LASTEXITCODE) { throw 'Evaluation failed' } } finally { Write-Output "elapsed: $($timer.Elapsed.TotalSeconds)s" }
```

See [automation](../scripts/README.md) for import and [tests](../tests/README.md) for fast validation. No reference-file argument is provided to teacher collection or specialist training. No publisher train references were scored to repair this run's labels.

## Azure And Next Experiment

No Azure ML job or GPU node was started; GPU shutdown has therefore not been tested. Future GPU execution must use minimum zero/maximum one nodes, a 120-second idle scale-down interval, bounded job duration and a final check of actual zero nodes, as specified in the [AML safety contract](../docs/AML_INFRASTRUCTURE.md#job-termination-contract). IaC, private data access and cloud smoke tests remain pending. Do not create a public storage workaround or reuse existing project resources to run this baseline on a GPU.

The next scientific question is whether a genuinely audio-capable generative teacher, given only the sanitized signal and defensible task context, can produce useful labels on a bounded development protocol. Better hardware does not establish that capability. Revisit teacher competence and label coverage before larger specialist training. Any subsequent strategy must preserve the [visibility contract](../docs/CONTEXT.md#data-visibility-contract), the already consumed final-set boundary and the [promotion protocol](../docs/VALIDAZIONE.md).
