# Select Pruning With Matched Crossed Tests Before Final Evaluation

**Collect removal effects with the reference bank fixed, then choose one pruning policy and freeze it before a separate final test.** The current task executes exploratory acquisition only; it does not adopt a pruned production input or run the final evaluation. Wrong class assignments and wrong acceptances have priority over false rejections. A reduction in review requests is not an improvement if unacceptable assignments return.

## Freeze Forty-Six Decisions Before Observing New Outcomes

The three primary factors are explicit dominant-frequency tracking (`ridge`), autocorrelation and band power. Test every presence/absence combination, including the full control and all three removed. The factorial cases are Ottawa D03 and D07, each with the true reference present and excluded: eight variants by four paired cases, or 32 decisions. They are development cases deliberately chosen from prior errors, not untouched validation data.

Add eight regression decisions: Ottawa D01 and Jin T01, each known/excluded, tested with the complete input and all three primary factors removed. Add two targeted D07 known/excluded decisions removing only spectral kurtosis. Add four exact-request replicates: repeat the full and triple-removal arms for Ottawa D03 known and excluded. Total: 46 new decisions, with one registered HTTP attempt per decision and no automatic retry. Stop on technical failure and preserve every receipt; a deliberate continuation requires a new registration and exact-input reuse checks.

The factorial estimates describe the direction of removal effects, including dependence on other retained views. Score individual removals, combinations and restored-view contrasts on the same cases; report each case transition as well as aggregates. The four repeats check limited response instability, not population confidence intervals. Do not expand the matrix or tune the prompt after seeing results.

## Remove Explicit Evidence Channels Completely

For each removed view, exclude its image cell, view metadata, numerical summary, per-view distance control and guide entry. Band-power and autocorrelation measurements also occur in the original interval report and must be removed there. Mask only the removed cells on the existing contact sheets; preserve canvas dimensions, retained-cell position, pixel content and image detail setting. Keep full controls under the same data-assembly and decision protocol.

Related representations can still contain overlapping physical information. Removing dominant-frequency tracking does not erase frequency evidence from FFT or STFT; this experiment tests the marginal effect of an explicit presentation channel in the presence of the others. It cannot establish that a physical frequency component has been eliminated from the model's information.

Use the same model, version, reasoning effort, maximum output allowance, references, reference order and binary decision schema in every arm. Supply only the retained diagram guide. In every fresh request, ask for reference discrimination first, examination of all supplied views, then the query decision, decisive evidence and counterevidence. This is one matched request protocol, not the earlier separate two-call survey; historical audit answers are contextual evidence only. No earlier survey or rationale may be copied into an arm, because it could reveal removed evidence.

## Rank Safety Before Recognition And Compactness

Report correct known recognition, wrong known assignments, false rejections, correct excluded rejection and wrong acceptance with their own denominators. Keep technical failures separate. Within the factorial, compare removal effects separately for known and excluded cases and list discordant cases. Do not count four decisions on two paired recordings as four independent acquisitions.

A pruning candidate should produce no observed increase in unacceptable assignments, retain the matched correct recognitions in the regression cases and reduce unnecessary rejection or evidence burden. Conflicting repeats or a trade-off between recognition and wrong acceptance require more development evidence; they do not authorize automatic selection. The spectral-kurtosis test is a targeted two-case probe, not a general recommendation to remove that representation.

All Jin directional acquisitions are already consumed; a genuinely clean Jin confirmation needs new source acquisitions. Previously consumed Ottawa profile 8 is not clean either.

A class already tied to one physical motor still cannot support independent-machine generalization.

Report the unchanged primary safety metrics and all technical attempts. If those results cause another pruning change, the set becomes development data and a new clean evaluation set is required.
