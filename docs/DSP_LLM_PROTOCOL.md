## Frozen Protocol

Registered before model requests. This exploratory test measures evidence-packet comparison; operational error and coverage targets remain unspecified. Diagnostic outcomes are scored separately from transport/schema compliance. The DSP generator is independent of the LLM.

The evidence format is `modelmetis.dsp-evidence/1`: one native-rate channel/interval per packet, seven-significant-digit scalar measurements, exact integer counts, explicit units and limitations, and two unchanged lossless PNGs: the full-band/fixed-low-frequency FFT amplitude plot and the STFT PSD image. Welch power, bands, envelope peaks and autocorrelation measures are provided as numbers, not redundant images. Three references plus a query use eight images; whole-condition holdouts use six. Images retain 1200 by 700 pixels and `detail=high`. Source identities, hashes, file paths, query truth and source sample offsets remain in the local audit, outside the diagnostic text. Plots retain their physical time axes. The selection of these two views is an efficiency hypothesis, not a proven optimal representation.

Each request supplies the complete allowed known-condition map, with opaque C01/C02/C03 condition IDs and R01/R02/R03 reference IDs. The query ID is Q01. The model must produce a strict structured object with outcome `known`, `outside_reference` or `indeterminate`; `condition_id` is null except for a visible known condition; `evidence_ids` cite supplied packet measurement/image IDs; `explanation` states observed comparisons; `limitations` records caveats. Missing, fabricated or inconsistent identifiers are technical failures. Outside-reference is not a new fault label. Self-reported confidence is deliberately absent.

Comparisons require identical source sample rate, valid interval duration, DSP configuration, implementation and dependency versions, channel policy, and declared input-processing history. Exact decoded source duplicates are blocked. These checks establish computational comparability only; they do not certify recording gain, microphone position, machine identity, steady regime or independence. No one file-level class is inferred from an interval.

Reuse the six original, amplitude-preserving drone A/B clips prepared under EXP-011, verifying the existing preparation audit, manifest and source hashes. The frozen physical allocation remains A for one publisher-labeled reference per condition and B for one query per condition: N (C01), MF1 (C02), PC1 (C03), F maneuver, mic1. The selection was by lowest PCM hash with a paired microphone counterpart, not a model result. Regenerate deterministic DSP reports with the unchanged DSP v1 parameters, then package the sole half-second interval. No C archive/rows, fresh download, reselection or additional human diagnosis is allowed. Publisher labels simulate human-confirmed initial references; query labels remain sealed to the evaluator.

Schedule: three all-known query requests, followed by three leave-one-condition-out folds, each with all three queries. This yields twelve trials: nine known and three unknown, over only three distinct query clips and one query drone. Entire conditions and their descriptions/images are absent in the respective holdout request. Calls are stateless, with no earlier answers or query-specific prompt edits. B was already development data; drone types, background mixtures and unresolved source-take lineage remain confounds. No independent-acquisition or heavy-vehicle population claim is permitted.
