# Experiment History

This is the chronological record of ModelMetis experiments, including negative results, incomplete runs and infrastructure blockers. Started September 18, 2026. The [confirmed objective and visibility contract](CONTEXT.md#objective) control every attempt. Documentation and reports are in English. Raw audio, sample-level predictions, publisher references, source mappings and model caches remain outside Git.

## Publication Conclusion, September 19

The idea has not worked in its tested form. General-model labels were too inaccurate to establish useful specialist learning, and context, normalization and one-shot support did not resolve that limitation. The Jin spectral one-shot control reached 12/12 on the same queries and with the same labeled support that yielded GPT Audio's 6/12. The teacher's failure cannot therefore be attributed solely to uninformative data under that split. This is a negative result for the tested approach, not proof against every possible teacher or architecture. Continuing to accumulate labels from this teacher is not supported by the evidence. Unknown motor/session independence, acquisition confounds and only four held-out Jin recordings prevent broader diagnostic claims. No production model was promoted. The published record preserves protocols, unsuccessful attempts and aggregate evidence, rather than presenting a completed software run as diagnostic success.

## Objective And Evidence Rules

Simulate unlabeled audio arriving over time. An audio-capable generative LLM interprets it and produces fallible silver labels or abstains. Accumulated silver data trains cheaper specialists. Iterate prompts, defensible technical context, representations and specialist strategies; progressively automate experiment selection. Evaluate usefulness independently, not by agreement with the teacher alone. Migrate eligible traffic only when measured quality and total cost justify it, with fallback and rollback. Publisher annotations never become student targets or query answers. Starting with EXP-006, the user authorizes a small disjoint labeled support set simulating human annotations, explicitly separated from both silver training and evaluation.

Every attempt receives a stable ID and preserves its configuration and result. Register the hypothesis and stopping rule before accessing evaluation feedback. Mark executed stages separately: capability check, development screening, silver collection, specialist training, independent evaluation, routing. A failed screening is not a completed end-to-end run. Do not omit failed commands, timeouts, empty collections, absent classes or rejected candidates. Record software tests separately from model performance.

Development metrics may guide a bounded next attempt. The Ottawa v1 final set was examined during EXP-001 and is now consumed for blind validation. It may be used only as a disclosed regression set; further tuning cannot produce a fresh final-test claim on it. Repartitioning the same already examined recordings does not restore independence. A successful development method still needs a new confirmatory dataset or independently reserved acquisitions before promotion.

For each record retain UTC execution dates where measured, dataset version and split hashes, model revision and resolved weight hashes, exact prompt/configuration, code/dependency version, random seed, accepted/abstained/failed counts, silver class coverage, training targets' provenance, teacher/student quality and latency, available cost evidence, artifact hashes, termination state and limitations. Never invent missing historical measurements. Pending fields stay explicitly pending. Cloud GPU runs require the [termination contract](AML_INFRASTRUCTURE.md#job-termination-contract); no shutdown claim is supported merely by a submitted minimum-zero configuration.

## EXP-001: CLAP Distillation Baseline

The original hypothesis was that a general pretrained audio-text model could provisionally label eight electric-motor conditions and provide targets for a lightweight classifier. This was explicitly a non-LLM baseline. Source audit verified 128 ten-second microphone acquisitions from Ottawa UOEMD-VAFCVS v2, DOI `10.17632/msxs4vj48g.2`, CC BY 4.0, Mert Sehri and Patrick Dumond (2026). All CSV/MAT pairs matched; opaque IDs, canonical WAV and separate references were created before inference. Sixteen development recordings used speed profile 1, 96 training recordings profiles 2-7 and 16 final recordings profile 8, with both loads included. Same physical motors across partitions limit interpretation.

EXP-001A and EXP-001B used the two exact text dictionaries preserved in [audio-prompts.json](../configs/audio-prompts.json). Highest development macro-F1 selected `acoustic`; input order broke ties. Both achieved only 12.5% accuracy. Prompt selection was written at `2026-09-18T09:32:52Z`, before collection and final evaluation. Selection did not establish teacher competence. Threshold zero deliberately accepted every valid top-one similarity as a baseline; scores were not calibrated confidence.

The pinned teacher was `laion/clap-htsat-unfused@8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a`. The selected prompt SHA-256 was `25cbe12f81776e52478ca635df90b1ab88b8b6c867b9a428d318e01017022446`. Its 96 silver targets covered just three categories: 48 healthy, 39 broken rotor bars and nine bowed rotor. The other five classes had no training examples. No original labels repaired this collection. Training used 48 log spectral bands, StandardScaler and logistic regression, maximum 1000 iterations, random seed 17. The artifact was written at `2026-09-18T09:36:35Z`; final evaluation at `2026-09-18T09:38:00Z`.

### Technical Attempts And Recovery

- The package tool reported PyTorch installed, but the ARM64 interpreter could not import it. Wheel availability checks found no compatible wheel in the inspected feeds. A separate existing-x64-Python environment resolved execution without changing the application interpreter.
- Direct PyPI download failed TLS; the configured package proxy succeeded without disabling certificate validation. A dependency snapshot of 48 packages passed `uv pip check`.
- One guessed source-file API returned 404; the publisher ZIP URL succeeded. Initial archive inspection assumed hyphenated names and found none; underscore names supplied the documented classes. Import checked 128 nonempty format pairs, not a zero-result search.
- Transformers downloaded an automatic safetensors conversion at a second revision. Both artifacts were hashed; all 447 named tensors and dtypes compared exactly equal. Requested revision alone did not capture all fetched files.
- The deprecated processor argument `audios` was changed to `audio` before the second development run and validated by real inference. Local lint defects were repaired and retested; the completed Python suite passed 61 tests with two dependency deprecation warnings and no skips.
- An optional West Europe AML A100 quota request failed with `QuotaNotAvailableForResource`. No billable resource or GPU job was created; existing T4 quota is sufficient for the proposed future initial cluster. This is an infrastructure result, not a model experiment or a shutdown test.

Campaign accounting is implemented and locally tested. One shared ledger spans prompt comparisons and collection, with exclusive locking and atomic, flushed writes.
